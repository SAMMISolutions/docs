title: "Array Reverse"
num: 7.1
redirect_from:

---

Flips the order of an array, so the last value becomes the first one. The array itself is changed, nothing is copied.

Objects and arrays stored inside the array keep working, they are moved along with everything else.

| Box Name | Type | Description | 
|-------|--------|--------
|Array Name	|String	| Name of the array you want to reverse
{:class='table table-primary'}

| Array | Result | 
|-------|--------
|["yellow","red","blue"] | ["blue","red","yellow"]
|[1,2,3,4,5] | [5,4,3,2,1]
{:class='table table-secondary w-auto table-hover' }
